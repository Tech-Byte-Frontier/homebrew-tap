# Tech Byte Frontier Homebrew tap

```sh
brew install tech-byte-frontier/tap/jevgate
```

| Formula | What it is |
|---|---|
| [`jevgate`](Formula/jevgate.rb) | [JevGate](https://github.com/Tech-Byte-Frontier/jevgate), a code-review gate for CI and coding agents |

The formula installs JevGate's release binaries for macOS (Apple silicon and Intel) and Linux (x86_64 and arm64). JevGate's release workflow updates it with each release; don't edit it by hand.
